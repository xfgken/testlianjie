# 快速访问链接集合

收集所有可用的访问入口，点击直达或按方法访问。

---

## 一、本地存储访问（车机/手机）

### 方式1：点击链接（可能受浏览器限制）
- [本机内部存储 /sdcard/（点击打开）](file:///sdcard/)

### 方式2：地址栏直接输入（最可靠）
在浏览器地址栏手动输入以下地址后回车：

```
file:///sdcard/
```

> ⚠️ 注意：`file://` 本地路径能否打开取决于浏览器是否允许本地文件访问。
> 部分车机/安卓浏览器默认禁止网页访问本地文件，若点击链接无效，请改用「地址栏直接输入」。

## 三、车机使用指引

- 若在车机浏览器上 **点击链接无法打开本地目录**，请在地址栏**手动输入** `file:///sdcard/`
- 网络链接在任意浏览器点击均无障碍，可直接跳转。
- 建议将常用入口保存到车机浏览器**书签**，快速访问。
